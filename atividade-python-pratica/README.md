# Atividade Prática - Python

Este projeto apresenta um script em Python para cálculo de médias escolares e demonstração de boas práticas.

## ⚙️ O que o código faz
Calcula a média de duas notas pré-definidas e exibe o status de aprovação.

## 🚀 Como Executar
Execute o comando no terminal: `python script.py`
